Debug Page: Floating Pills Navbar

This debug page tests if the Floating Pills navbar is working correctly.

You should see a floating navbar on the left side that expands when you hover over it.

What to Test:

  • Navbar should appear as floating pills on the left
  • Should expand on hover
  • Brand logo should be in a circle
  • Navigation items should be pill-shaped
  • Language toggle should be at the bottom

If you can see and interact with the navbar, then the CSS is working. If not, there's a CSS loading issue.
